# BEFORE THE STARS

**Ver.1.0 β9 / 2026-10-24公開**

1775年6月から始まるアメリカ独立戦争の戦略シミュレーションです。独立派・王党派のどちらでもプレイできます。

## プレイ

公開URLの `index.html` が入口です。ZIPで入手した場合は全体を展開し、`index.html` を開いてください。フォルダ構成を保ってください。

PC・タブレットの横向き表示をおすすめします。スマートフォンやタッチ操作の機種別検証は完了していません。

遊び方・作品情報・利用条件は [about.html](about.html) にあります。
公開済み修正・開発中の課題は [更新履歴（CHANGELOG.md）](CHANGELOG.md) を参照してください。

## β版の状態

公開更新ごとにβ番号を進め、公開日・変更内容・検証結果を `CHANGELOG.md` に追記します。β8はβ7までの公開修正を引き継いでいます。各日の公開記録は履歴に残しています。

β8では、王党派AIがウスター／ボストンの開戦直後を優先しつつ、戦線再編後に「2州票の獲得」を軍事・南部拠点構築と並行する長期戦略目標として保持する候補処理を追加しました。政治工作と治安コマンドを組み合わせ、予備役指揮官の安全な別働隊編成も候補化します。初期軍事資金3,000／4,500／5,000／5,500／6,000を比較し、王党派の**初期軍事資金のみ3,000→5,000**を採用しました。独立派の軍資金・議会国庫は変更しません。試遊の詳細・残課題は [開発時の試遊報告](BETA8_PLAYTEST_REPORT.md) を参照してください。

初期軍資金の増額は**新規ゲーム開始時のみ**です。β7以前の保存データの軍資金を読み込み時に自動加算するものではありません。

港湾封鎖した港で継続戦闘になった場合、翌月の月初確認で「維持（通常コマンド1）」または「解除」を選択します。戦闘が終了した、制海権を失った、コマンドが足りない場合は維持できません。AIも同様に維持費を払います。勝敗閾値・海上退路の法的判定などは従来どおりです。

援軍は陸路・海路のどちらでも、継続戦闘に参加している間は**戦場に部隊旗**を表示します。既存の地図上の「→」が出発都市・移動方式・参加部隊を示し、矢印や会戦マークを押して開く会戦情報には、参加部隊名・指揮官・出発地・補給状況を文章でも表示します。出発都市の陥落で援軍の戦闘参加そのものが消えるわけではありません。補給遮断による士気0の実際の部隊崩壊では、独立した月次報告を表示します。

β9では、独立派AIが5州票を確保した後、王党派の実際の軍事拠点を中期攻略目標に設定し、戦力集結・陸上前進・好機における攻撃・占領後の保持へ接続します。敵の総司令官を捕縛して直ちに終戦させる追跡専用戦略は追加しません。危機対応・移動可否・補給・戦闘予測・信任安全の既存条件を尊重します。診断と限界は [BETA9_PATRIOT_BASE_CAMPAIGN_AUDIT.md](BETA9_PATRIOT_BASE_CAMPAIGN_AUDIT.md) を参照してください。

王党派が北部を離脱して陸上の現実的な攻略目標がないときは、敵拠点へ続く海港・航路も検討します。到着率の悪い上陸を強要せず、航路で最も制海権が不足する海域の哨戒を攻略準備に結び付けます。作戦影響値が上限に達しても上陸が危険なら、無意味な哨戒優先を止めて他の戦略条件の変化を待ちます。制海権が改善してからも、上陸・海上移動の可否と損耗は既存の厳しい判定を通す必要があります。

β9では王党派AIの2票以降の戦略層を追加し、3票、4～5票を段階的に目指す接続を導入しました。軍事的な足場、治安維持、政治工作を組み合わせます。過去の診断は [BETA9_STRATEGY_AUDIT.md](BETA9_STRATEGY_AUDIT.md) に残しています。

封鎖維持の判断待ちを保存した場合も、「続きから」・手動ロード後に確認を再開し、維持費の支払い前に継続会戦へ進まないよう接続しました。

補給・守備隊の資源不足確認、両陣営のAI、海上輸送、保持から攻勢への準備評価を含みます。AIの攻勢判断と長期バランスは引き続き調整中です。

β7（2026-10-22公開）では、攻撃開始時に港湾封鎖が誤解除される不具合を修正しました。王党派の新規開始時の予備役にヒュー・パーシーを追加しました。旧セーブへは自動追加しません。

2026-10-21パッチでは、同等の新軍配置候補間での展開余地の評価、部隊命令後の備蓄同期、制海権参照処理の高速化を追加しました。新軍配置の長期的な戦果への効果は未判定です。

2026-10-20パッチでは、海上損耗・橋頭堡への反撃・退路を考慮したAI上陸判断と、継続会戦への逐次投入抑止を追加しました。計画的な初戦から翌月の援軍へつなぐ作戦AIも含みます。長期バランスと判断負荷は継続検証中です。

β6では危機時のAI戦線移転・別働隊集結と退却判断を調整しました。遠隔援軍を出発元の駐留兵力として数える表示・AI評価を補正し、都市情報に駐留将軍人数・野戦軍総兵力・一覧／詳細への案内を追加しました。長期バランスは引き続き検証中です。

β5では海上作戦の月次得点差を翌月へ引き継ぐ方式（上限±15点・自然減衰なし）へ変更しました。海上哨戒の陣営別文言と継続会戦監査も含めています。旧セーブに残っている作戦記録は移行しますが、旧版がすでに破棄した過去月の加点は復元しません。

β4では出撃・援軍派遣中の支配判定を統一しました。β3以前の継続戦闘セーブには出撃前の支配を証明する情報がないため、空になった出発都市の支配が変わる場合があります。今回の支配継続は新規開始・更新後の出撃から記録されます。

セーブは同じブラウザ内に保存され、端末・ブラウザ・公開URLをまたぐ同期はありません。更新時の互換性は保証していません。不具合報告には、バージョン、端末とブラウザ、陣営、ゲーム内年月、再現手順を添えてください。

## GitHub Pagesで公開する方へ

このフォルダの**中身**をリポジトリの公開対象へ配置してください。`index.html` が対象ディレクトリの直下になる構成です。npmやビルド処理、サーバー側プログラムは不要です。

ブランチから公開する場合は、そのブランチと配置先に合わせてPagesの公開元を指定します。`.nojekyll` も含めて配置してください。ZIPそのものを置くだけではプレイ用サイトになりません。

ゲームの実行用JavaScriptと素材は `runtime/` にあります。古い番号を含む一部の内部ファイル名は互換性と参照維持のため残しています。公開バージョンの表示とは別です。
