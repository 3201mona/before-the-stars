# BEFORE THE STARS

**Ver.1.0 公開テスト版（β版） / 2026-10-17**

1775年6月から始まるアメリカ独立戦争の戦略シミュレーションです。独立派・王党派のどちらでもプレイできます。

## プレイ

公開URLの `index.html` が入口です。ZIPで入手した場合は全体を展開し、`index.html` を開いてください。フォルダ構成を保ってください。

PC・タブレットの横向き表示をおすすめします。スマートフォンやタッチ操作の機種別検証は完了していません。

遊び方・作品情報・利用条件は [about.html](about.html) にあります。

## β版の状態

補給・守備隊の資源不足確認、両陣営のAI、海上輸送、保持から攻勢への準備評価を含みます。AIの攻勢判断と長期バランスは引き続き調整中です。

セーブは同じブラウザ内に保存され、端末・ブラウザ・公開URLをまたぐ同期はありません。更新時の互換性は保証していません。不具合報告には、バージョン、端末とブラウザ、陣営、ゲーム内年月、再現手順を添えてください。

## GitHub Pagesで公開する方へ

このフォルダの**中身**をリポジトリの公開対象へ配置してください。`index.html` が対象ディレクトリの直下になる構成です。npmやビルド処理、サーバー側プログラムは不要です。

ブランチから公開する場合は、そのブランチと配置先に合わせてPagesの公開元を指定します。`.nojekyll` も含めて配置してください。ZIPそのものを置くだけではプレイ用サイトになりません。

ゲームの実行用JavaScriptと素材は `runtime/` にあります。古い番号を含む一部の内部ファイル名は互換性と参照維持のため残しています。公開バージョンの表示とは別です。
